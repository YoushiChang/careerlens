01

岗位职责

  • 负责平台 CPS 增长体系的整体规划与产品设计，包括 CPS 合作模式（商家 / 达人 / 渠道 / 联盟）、佣金结构、激励机制、结算与风控规则，并抽象可复制的 CPS 增长模型。
  • 建设选品与转化能力：CPS 商品池、转化分层、佣金效率评估。
  • 建设分发与撮合能力：达人 / 渠道匹配、素材与链路能力。
  • 建设归因与结算能力：点击 / 下单 / 成交归因，防作弊与异常识别。
  • 建设数据与看板能力：GMV、ROI、履约、留存等核心指标体系。
  • 对 CPS GMV、成交转化率、平台整体 ROI / 利润贡献、新客、复购、供给侧活跃度等核心指标负责。
  • 与商业化、平台招商、内容 / 达人、风控、财务等团队深度协作，在效率、体验与风险之间做取舍。
02

任职要求

  • 本科及以上学历，3 年以上产品经验。
  • 有 CPS / 联盟营销 / 电商增长 / 商业化产品相关经验者优先。
  • 熟悉电商或内容平台的交易、转化、激励机制。
  • 强业务理解力：能站在平台视角，而不是单一角色视角。
  • 结构化能力强：能把混乱的增长问题抽象成清晰产品模型。
  • 数据敏感、结果导向，关注真实转化与 ROI；推进力强，能在复杂协作和博弈中持续拿到结果。

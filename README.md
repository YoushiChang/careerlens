# 网页样式与脚本路径修复

当前 GitHub 仓库的样式和脚本位于根目录。本修复包已改为全部使用根目录文件，不依赖 assets 子文件夹。

1. 在 https://github.com/YoushiChang/careerlens 打开 Add file → Upload files。
2. 打开本地 github-fix-upload 文件夹，选择里面的全部文件，拖入 GitHub 上传区。不要上传这个外层文件夹。
3. 页面底部点击 Commit changes，提交到 main。GitHub 会更新同名文件。
4. 等待 Pages 自动重新发布，打开 https://youshichang.github.io/careerlens/ ，按 Ctrl+F5 刷新。

无需改动 Settings → Pages。修复包括所有 HTML 页、样式、脚本、PDF worker 和岗位网关地址。

岗位网关仍由 https://careerlens-zys.plaidatoll2.chatgpt.site 提供。
